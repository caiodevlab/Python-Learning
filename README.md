# 🐍 Python Learning

Repositório criado para registrar minha jornada de aprendizado em **Python**.

Aqui estão exercícios, tarefas, desafios, testes, experimentos e pequenos projetos desenvolvidos durante meus estudos.

O objetivo não é apenas guardar códigos, mas acompanhar minha **evolução na programação**, desde os fundamentos até projetos mais completos.

Os estudos estão organizados por assunto:

* Fundamentos do Python
* Variáveis e tipos de dados
* Operadores
* Entrada e saída de dados
* Condicionais
* Loops
* Listas e tuplas
* Dicionários e conjuntos
* Funções
* Manipulação de arquivos
* Módulos e pacotes
* Programação Orientada a Objetos
* Projetos
* Desafios
